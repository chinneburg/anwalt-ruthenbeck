# Rechtsanwälte & Notar Ruthenbeck

Responsive, static website for the Ruthenbeck law firm in Sprockhövel.

## Preview

Serve this directory with any static file server. For example:

```sh
npx serve .
```

The site has no build step or runtime dependencies.

## Before publication

- The privacy page carries over the previous site's February 2020 text and explicitly describes features such as a contact form, cookies, and Google Analytics. Review and update it against the actual hosting and site functionality before publication.
- The imprint is based on the information on the previous site. Confirm the legal wording and firm details before publication.
